## About the course

This practical WSQ course preserves the approved Social Media Marketing competency coverage for planning, creating, measuring, optimizing, and managing Facebook campaigns. It adds an agentic operating model: structured evidence, narrow tool contracts, approval gates, traceable decisions, privacy controls, rollback rules, and human oversight.

All learner labs use fictional Lumina Living data. No live advertising account, customer record, credential, or paid API is required.

## Learning outcomes

By the end of the course, learners will be able to:

- develop a plan for a Facebook social media marketing campaign;
- evaluate social market opportunities for a Facebook campaign;
- monitor Facebook social media marketing performance;
- determine campaign feasibility by optimizing Facebook advertisements;
- evaluate campaign usage and its organisational impact; and
- establish measurable social media marketing objectives.

## Topics covered

1. Plan an agentic social media campaign: KPI trees, persona evidence, journey states, opportunity scoring, agent architecture, tool contracts, policy, privacy, and intellectual property.
2. Create campaigns with governed agents: campaign hierarchy, creative briefs, brand voice, audience controls, content review, approvals, placements, and experiments.
3. Measure performance and agent decisions: event pipelines, CTR/CVR/CPL/ROAS, funnels, attribution, reporting, anomalies, retargeting, and agent traces.
4. Optimize campaigns with controlled experiments: A/B decisions, marginal return, creative fatigue, audience overlap, scheduling, platform feasibility, and rollback.
5. Manage communities with human oversight: intent and sentiment, moderation, UGC rights, crisis escalation, advocacy, organisational impact, and AI governance.
